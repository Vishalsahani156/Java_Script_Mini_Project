JavaScript Mini Projects
This repository showcases a collection of beginner-friendly JavaScript projects that emphasize core concepts such as DOM manipulation, event handling, asynchronous functions, and Promises. Each project is built using HTML, CSS, and vanilla JavaScript to reinforce foundational web development skills.

🛠️ Technologies Used
HTML5: Structuring the content of web pages.

CSS3: Styling and layout of web pages.

Vanilla JavaScript (ES6+): Implementing functionality without external libraries.

DOM Manipulation: Interacting with and modifying the Document Object Model.

Event Handling: Responding to user interactions such as clicks and input.

Asynchronous JavaScript: Utilizing async/await and Promises for handling asynchronous operations.
